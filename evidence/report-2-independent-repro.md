## 三、复现2 vs 优化前：提速账

- **缓存命中率**：10.1% → **98.5%**（+88.4 个百分点）
- **重算 token**：72,986 → **1,759**，**少了 41.5 倍**
- **命中前缀**：8,192 → **118,898**，**多了 14.5 倍**
- **TTFT**：206.9s → **33.2s**，省 **173.7 秒**

### 为什么复现2 的 TTFT（33s）比复现1（3.1s）高？
需要诚实说明，这恰恰证明诊断是有分辨力的：
- 复现1 的 suffix 只有 627 token，重算极快 → TTFT 3.1s。
- 复现2 是**全新会话、更大旧档**，suffix=1,759 token 且本次输出 3,168 token（比复现1 的 3,444 少，但上下文更大、系统头 7,175 字也不同），生成阶段占 110s。
- **TTFT 绝对值取决于"需要重算的后缀量"**，而不是命中率本身。两次都命中率 98%+、后缀都只有千 token 级——**这才是"缓存对齐"带来的本质改善**。优化前是 7.3 万 token 全量重算（TTFT 206.9s），优化后是 1-2 千 token（TTFT 秒级到几十秒，取决于增量大小）。
- 这也说明**命中率从 10% 回 98%+ 是稳定现象**，与具体会话无关。
